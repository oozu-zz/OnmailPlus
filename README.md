# 온메일플러스

온메일의 화면 구성과 키보드 사용성을 개선하는 userscript/usercss 및 Chrome/Edge Manifest V3 확장입니다.

## 확장 설치

1. `chrome://extensions` 또는 `edge://extensions`를 엽니다.
2. 개발자 모드를 켭니다.
3. `압축해제된 확장 프로그램을 로드`를 선택합니다.
4. 저장소의 `extension` 폴더를 선택합니다.
5. 온메일 탭을 새로고침합니다.

`extension` 폴더에는 `온메일플러스` 확장으로 바로 로드할 수 있는 Manifest V3 파일이 들어 있습니다.

## 포함 기능

- 메일 목록 방향키 이동 및 Enter 열기
- 좌우 방향키 페이지 이동
- 보낸사람 이름 클릭 검색
- 메일쓰기/메일읽기 단축키
- 첨부파일 및 전체 다운로드 단축키
- 메일 목록 줄 간격 저장 및 순환 변경
- 메일 분할 리사이저 위치 보정
- 온메일 화면 레이아웃 및 가독성 보정

원본 userscript와 usercss는 `userJS` 및 `userCSS` 폴더에서 확인할 수 있습니다.
