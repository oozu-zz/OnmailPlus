# 온메일플러스

온메일의 화면 레이아웃과 키보드 사용성을 개선하는 Chrome/Edge Manifest V3 확장입니다.

## 설치

1. `chrome://extensions` 또는 `edge://extensions`를 엽니다.
2. 개발자 모드를 켭니다.
3. `압축해제된 확장 프로그램을 로드`를 선택합니다.
4. 이 폴더(`extension`)를 선택합니다.
5. 온메일 탭을 새로고침합니다.

온메일 페이지의 전역 함수와 연동하는 기능이 있어 콘텐츠 스크립트는 페이지 실행 영역에서 동작합니다. 확장 설치 후 온메일 탭에서만 권한이 사용됩니다.
